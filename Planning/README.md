# Planning

This section focuses on brainstorming the ideas behind the project, specifically the main topic it will be focused on.

Check out [The ideas folder](./Ideas)

## Requirements

### Follow the main idea

The main idea as mentioned is:

> Build a technical solution that helps families with everyday needs or wellbeing, using AI tools

All ideas must follow this guideline.

You can simply add a new file to the Ideas folder to suggest your idea for now.

### Naming

File names must be descriptive

```
my_idea_name.md
```

Example would be `family_help_page.md`

### Summary

All ideas must have a short summary at the top that summarizes all that is written below it into 3 or 4 short sentences.

### Problem

What problem is your idea trying to solve?

### Solution

How would your tool fix that problem?

### AI Contribution

How would AI work with your tool towards the solution?

### Prototype

What would your demo look like?
